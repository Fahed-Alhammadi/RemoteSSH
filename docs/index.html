Everything in one window

Browse, compare, transfer and edit without switching apps. The Mac app is native SwiftUI; on Windows and Linux it runs on Electron with the same features.

  • Both sides at once

    Local and remote folders side by side, with sortable columns, a filter, hidden files and drag and drop between them.

  • See what changed

    Directory comparison marks files that are newer, missing or different. Synchronized browsing follows you into the same folder on both sides.

  • A queue that keeps going

    Parallel transfers, automatic retries, resume and speed limits. The queue survives restarts, and you decide what happens when a file exists.

  • Edit in place

    Open a remote file in your own editor. RemoteSSH uploads it again each time you save.

  • SSH terminal

    Open a shell on the server, in the folder you're looking at, from the panel below the panes.

  • Your sites, one click away

    Save servers with their login, folders and settings. Export them as one .remotessh file that opens on every platform.

Drag it over. It's on the server.

Drop files between the panes or from your file manager. RemoteSSH queues them, shows progress, retries if the connection drops and resumes where it stopped.

  • Overwrite, skip, resume, rename, or only if newer
  • Separate connections, so browsing never waits for a transfer
  • Queued, failed and finished transfers in their own tabs

A terminal when the files aren't enough

Unpack an upload, check a log or restart a service without leaving the app.

  • Opens in the remote folder you're viewing
  • Runs on its own connection, so long commands never block transfers
  • Toggle it with Ctrl + ` on every platform

It asks before it trusts a server

Your password is only sent once RemoteSSH knows who it's talking to.

  • FTPS certificates are checked before you log in; if one can't be verified, you decide whether to connect
  • SFTP host keys are remembered and shown as SHA-256 fingerprints, with a warning if a key changes
  • Passwords go to the macOS Keychain, Windows DPAPI, or the Secret Service or KWallet on Linux
  • The released Mac app only installs updates signed by the same developer
