Move files between your computer and your servers.

RemoteSSH is a free, open-source file transfer client for SFTP, FTP and FTPS. Two panes side by side, one transfer queue, and nothing to sign up for.

Everything in one window

Connect

  • Quickconnect bar for one-off servers: type the address, press Connect.
  • Site Manager with folders, logon types (normal, anonymous, ask for password, key file) and a default local and remote folder per site.
  • Import and export your sites as a .remotessh file. The same file opens on every platform, with passwords only if you choose.

Browse

  • Local and remote side by side, with sortable columns, a filter and hidden files.
  • Directory comparison highlights files that are newer, missing or different on either side.
  • Synchronized browsing follows you into the same folder on both sides.
  • Edit in place: open a remote file in your editor and RemoteSSH uploads it again when you save.

Transfer

  • Drag and drop between the panes or from your file manager.
  • A queue that survives restarts, with parallel transfers, automatic retries and resume.
  • You decide what happens when a file already exists: overwrite, skip, resume, rename, or only if newer.
  • Speed limits for uploads and downloads (on the Mac, for FTP and FTPS).

Keep up to date

  • Automatic updates from GitHub releases: RemoteSSH checks at startup, downloads, installs and relaunches.
  • Native on the Mac, built with SwiftUI. On Windows and Linux it runs on Electron with the same features.
  • Light and dark, following your system setting.

It asks before it trusts a server

  • For FTPS, the certificate is checked before your password is sent. If it can't be verified, you see exactly what the server presented and decide.
  • For SFTP, host keys are checked against SHA-256 fingerprints, and you are warned if a server's key ever changes.
  • Saved passwords go to the system keychain: macOS Keychain, Windows DPAPI, or the Secret Service or KWallet on Linux. Without a keyring, RemoteSSH asks each time instead of storing them in plain text.
  • The Mac app is signed with a Developer ID and notarized by Apple, and it only installs updates signed the same way.
